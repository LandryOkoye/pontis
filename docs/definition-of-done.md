## What remains

1. **Frontend.** There is no `apps/web` on `main` and no frontend branch or pull request on the remote (checked 2026-11-10). Items 4 to 6 and the web tests in item 10 stay open until it is merged. After that, add the web walkthrough to the demo script and run the end-to-end run against the deployed contracts with `E2E_MODE=testnet`.
2. **Use a keyed RPC endpoint** before relying on the Testnet run. The previous status note recorded one conversion settling through the indexer on Testnet (about a minute after the transaction); this review did not re-run it. The free public endpoints rate limit (`429`) the indexer, reconciler and API together, so a full `E2E_MODE=testnet` run is not reliable on them ([local setup](local-setup.md), RPC endpoints).
3. **Redeploy after contract changes.** The contracts on Testnet are the build deployed on 2026-11-09; any later contract change reaches Testnet only through a redeploy (there is no migration, [known limitations](known-limitations.md)).
