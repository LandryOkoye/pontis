## What remains

1. **Merge the frontend pull request** (items 4 to 6, and the web tests in item 10), then add the web walkthrough to the demo script and run the end-to-end run against the deployed contracts with `E2E_MODE=testnet`.
2. **Use a keyed RPC endpoint** before relying on the Testnet run. One conversion settled through the indexer on Testnet (about a minute after the transaction), but the free public endpoints rate limit (`429`) the indexer, reconciler and API together, so a full `E2E_MODE=testnet` run is not reliable on them ([local setup](local-setup.md), RPC endpoints).
